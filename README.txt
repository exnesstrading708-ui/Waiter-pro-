Waiter Pro 5% Android wrapper project

This is Android Studio source, not a compiled APK. Build with Android Studio (JDK 17, Android SDK 35, Android Gradle Plugin 8.6.1): open this folder, sync Gradle, then Build > Build Bundle(s) / APK(s) > Build APK(s).

Important security note: the email/password gate in index.html is local-only and stores the password in the browser's local storage. It is NOT secure authentication and does not verify email ownership. Do not use a real/reused password. Real secure sign-in requires a backend/auth provider and email verification.
